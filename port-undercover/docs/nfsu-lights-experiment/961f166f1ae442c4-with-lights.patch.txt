# Headlights and tunnel lamps (core.nfsu setting headlights; 2026-11-18): the kit's
# RECOMP_D3D9_CAR_LIGHTS fills c14-c17 the inverse view projection, c18 the camera + light count, c19-c22 the view
# projection, c23 = (lights with shadows, unused), c24.. two per light - a headlight: position + strength,
# direction + cos of the cone's edge; a tunnel lamp (found by the kit among the frame's brightest spots): position +
# strength, its colour + -1 - and c88 the headlights' colour. Each pixel's world position comes back from the scene
# depth this pass reads (texture 2 decoded with c7, as the pass does), its normal from the screen derivatives of that
# position. A headlight lights it by its cone, the distance squared and the angle, weak right under the bumper,
# fading out by 70 m; the nearest four are shadowed where their light shows: 7 steps toward the lamp through the depth
# buffer (blocked when the surface there is 0.6-4 m nearer than the step). A lamp lights all round within 20 m. (A
# tunnel darkening filter here was taken out on the person's word, 2026-11-18: the tunnel's darkness is now the game's
# own baked shade made deeper, all-vertex.patch.) Light is added as scene x (1 + light / (8 x
# local blurred brightness + 0.04)), so it shows in the dark and hardly in daylight.

        const int ns_ = int(c[23].x + 0.5);
        const float3 eye_ = c[18].xyz;
        const float nn_ = dot(n_, n_);
        n_ = nn_ > 1e-12 ? n_ * rsqrt(nn_) : float3(0.0, 0.0, 1.0);
        if (dot(n_, eye_ - p_) < 0.0)
            n_ = -n_;

                const float3 v_ = lp_.xyz - p_;

                const float3 l_ = v_ / dist_;

                    continue;
